# Providers

`WalletProvider` is the bridge between adapters, hooks, and UI components.

```tsx
<WalletProvider
  adapter={adapter}
  allowedChains={[1, 137, 8453]}
  onChainMismatch="prompt-switch"
  modalType="default"
  theme="dark"
>
  <App />
</WalletProvider>
```

## Notes

- provider state is persisted through `storageKey`
- modal behavior is configurable
- chain mismatch handling is available at the config layer
