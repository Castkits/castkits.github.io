# Installation

Install only the layers you need.

```bash
pnpm add @castkit/core
pnpm add @castkit/ui @castkit/adapter-wagmi
pnpm add -D @castkit/adapter-mock
```

## Package Roles

- `@castkit/core`: hooks, types, utils, contexts
- `@castkit/ui`: buttons, panels, status components, provider
- `@castkit/adapter-wagmi`: default production adapter
- `@castkit/adapter-ethers`: ethers v6 alternative
- `@castkit/adapter-mock`: tests, Storybook, docs, local demos
